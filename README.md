# Ryosuke 
**Software Engineer & Applied Researcher | Cryptography • Edge AI • Mobile Architecture**

Welcome to my GitHub. I am a software engineer and researcher focused on the intersection of **privacy-preserving technologies (ZKP)**, **computer vision at the edge**, and **scalable cross-platform architecture**. 

I specialize in optimizing heavy computational workloads—such as Zero-Knowledge Proof generation and vision-language model (VLM) inference—on resource-constrained devices, while building robust applications that bridge hardware and software.

### 🔬 Core Research & Engineering Domains

* **Applied Cryptography & Web3:** Designing and benchmarking Zero-Knowledge Proofs (ZKP) circuits using Circom and Snark.js. Currently researching privacy-preserving proximity verification systems for Unmanned Aerial Vehicles (UAVs) without disclosing raw location data.
* **Edge AI & Computer Vision:** Architecting hierarchical object detection pipelines (YOLO, GroundingDINO, NanoOWL) optimized for NVIDIA Jetson devices. Deep expertise in resolving CUDA memory bottlenecks, TensorRT optimization, and Docker containerization for edge deployment.
* **Cross-Platform & Game Architecture:** Building high-performance mobile applications and interactive idle games. Focused on advanced state management, secure data handling, custom UI/UX, and audio integration (FlameAudio) using Flutter and React Native.
* **IoT & Hardware Integration:** Developing reliable Python-based data logging systems that interface directly with hardware (Raspberry Pi, GPS modules, I2C environmental sensors like BME280) for real-world data aggregation and analysis.
