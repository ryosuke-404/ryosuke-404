# Ryosuke 
**Software Engineer & Researcher | Applied Cryptography • Edge AI • Mobile Architecture**

Welcome to my GitHub. I am a software engineer and researcher focused on the intersection of **privacy-preserving technologies**, **computer vision at the edge**, and **scalable application architecture**. 

My current research and development efforts are dedicated to optimizing heavy computational workloads (like ZKP generation and LLM/VLM inference) on resource-constrained devices, alongside building robust, cross-platform mobile experiences.

### 🔬 Core Areas of Expertise

* **Applied Cryptography & Web3:** Designing and benchmarking Zero-Knowledge Proofs (ZKP) systems. Currently researching ZKP applications for Unmanned Aerial Vehicles (UAVs) to ensure data privacy and verifiable proximity without location disclosure.
* **Edge AI & Computer Vision:** Architecting hierarchical object detection pipelines (e.g., YOLO, GroundingDINO, NanoOWL) on NVIDIA Jetson architectures. Experienced in CUDA debugging, Docker containerization for edge devices, and memory footprint optimization.
* **Cross-Platform Architecture:** Building high-performance mobile applications and interactive idle games (using Flame) with Flutter and React Native. Focused on state management, secure data handling, and custom UI/UX implementations.
* **IoT & Sensor Integration:** Developing Python-based data logging systems interfacing with hardware (Raspberry Pi, GPS modules, I2C environmental sensors) for real-world data aggregation.
