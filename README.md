### 🔬 Core Research & Engineering Domains

* **Applied Cryptography & Web3:** Designing and benchmarking Zero-Knowledge Proofs (ZKP) circuits using Circom and Snark.js. Currently researching privacy-preserving proximity verification systems for Unmanned Aerial Vehicles (UAVs) without disclosing raw location data.
* **Edge AI & Computer Vision:** Architecting hierarchical object detection pipelines (YOLO, GroundingDINO, NanoOWL) optimized for NVIDIA Jetson devices. Deep expertise in resolving CUDA memory bottlenecks, TensorRT optimization, and Docker containerization for edge deployment.
* **Cross-Platform & Game Architecture:** Building high-performance mobile applications (e.g., *Oshikatsu Camera/Nikki*) and interactive idle games (*Yurupura*, *Burger Tap*). Focused on advanced state management, secure data handling, custom UI/UX, and audio integration (FlameAudio) using Flutter and React Native.
* **IoT & Hardware Integration:** Developing reliable Python-based data logging systems that interface directly with hardware (Raspberry Pi, GPS modules, I2C environmental sensors like BME280) for real-world data aggregation and analysis.

---

### 🚀 Featured Projects & Architecture Focus

* **Privacy-Preserving UAV System:** Architecting a system utilizing background location tracking and ZKP to generate secure proximity proofs for drones, bridging cryptography with mobile edge capabilities.
* **Hierarchical Edge AI Detection:** Engineering containerized NanoOWL/YOLO pipelines on Jetson devices for complex physical-world detection (e.g., specific objects within broader bounding boxes) while managing strict memory limits and `OOM` errors.
* **Mobile App Ecosystem:** End-to-end development of consumer-facing utility and gaming apps, featuring complex image processing (cropping/importing), secure in-app purchases (IAP), and engaging game loops.
